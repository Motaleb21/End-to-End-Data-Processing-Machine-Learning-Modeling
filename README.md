# End-to-End Data Processing & Machine Learning Modeling

## 📌 Project Overview

This project demonstrates an end-to-end machine learning workflow, from raw data processing and exploratory data analysis to model training, optimization, and evaluation.

The project includes both **classification and regression** tasks and compares multiple machine learning algorithms.

## 🎯 Objectives

- Clean and preprocess raw datasets
- Handle missing values and outliers
- Perform exploratory data analysis
- Prepare data for machine learning
- Train multiple machine learning models
- Perform hyperparameter tuning
- Evaluate model performance
- Compare different models

## 📊 Machine Learning Tasks

### 1. Classification

The classification task predicts whether an individual's annual income is:

- `<=50K`
- `>50K`

Models used:

- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Gradient Boosting
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Neural Network

### 2. Regression

The regression task predicts automobile prices using vehicle-related features.
